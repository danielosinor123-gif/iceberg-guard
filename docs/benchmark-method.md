# Benchmark method (MVP)

1. Same seeded dataset, two layouts written from it (never modified in place): `events_many_small` (30 batches) and `events_sorted_compact` (sorted by (category, ts), 4 batches). Benchmark operands are selectable: `benchmark --baseline <table> --candidate <table>`; the committed example compares the **intervention output** (`events_intervention_sorted`), not a pre-materialized twin.
2. Candidate interventions can be produced *by the tool*: `iceberg-guard rewrite --mode sort|compact` times the rewrite end-to-end, writes into a declared batch count, and verifies `digest_match` between source and rewritten table (correctness of the rewrite itself is a gate, not a nicety).
3. Workload = YAML manifest (`config/example-workload.yaml`): SQL templates with `{placeholder}` params, per-param weight, order-sensitivity, repetitions, timeout.
4. Every query × param set × repetition × layout: samples (ms), rowcount, digest. No best-of-run cherry picking; p50/p95 reported with rep count; layouts alternate within repetitions (interleaved) to damp ordering bias.
5. Result digest equality between layouts **gates** all timing claims. The gate is fail-closed: every expected unit from the workload manifest (recorded as `expected_units`) — not merely every unit present in the records — must exist on both layouts with status=ok, samples_recorded == repetitions, digest sets identical. Missing or partially-sampled expected units fail and are named. Empty comparisons can never pass. Float aggregates can legitimately differ in the 11th significant digit across layouts (DuckDB re-associates the sum across file splits); the cross-layout digest therefore rounds numeric columns to 1e-9 before hashing, a disclosed convention (see docs/limitations.md). Raw sums remain available in run records; integer/string results are compared exactly.
6. Cost-benefit framing: rewrite elapsed_sec and output layout are recorded, but conversion to an "is it worth it" verdict requires a read-frequency profile, which this synthetic workload lacks — no amortization claim is made or implied.
